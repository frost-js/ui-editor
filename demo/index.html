Editing and source

Format text, switch to HTML, and undo your changes. The default toolbar also provides links, images, YouTube video, tables, and fullscreen.

Use Ctrl/Meta+B, I, or U for formatting. Tab / Shift+Tab indent and outdent in rich and source modes. Escape, then Tab moves focus out. Use the handle below to resize.

Toolbars and custom buttons

Toolbar groups can be replaced per instance. Plugins run with the editor as their this value.

Custom action and editing tools

The “Insert greeting” button calls this.insertText(). This toolbar also exposes font size, lists, indentation, alignment, and history.

Custom plugin example 
UI.Editor.plugins.greeting = {
    content: "Hello",
    title: "Insert greeting",
    action() { this.insertText("Hello from a custom plugin! "); }
};
UI.Editor.init(textarea, {
    buttons: [["bold", "italic", "greeting"], ["source"]]
});

Media and tables

Click the link, image, or table cell for context actions. Toolbar dialogs insert links, images, and HTTPS YouTube URLs; the table picker inserts a new table.

The tiny embedded PNG needs no external image request. Select it to resize its width or change its float. Video content loads only when you insert a video.

Custom image upload callback

Choose an image in the Image dialog or drop one into the editor. This local simulation waits briefly, reads a raster image, and inserts its data URL; it sends no files to a server.

Waiting for an image.

Callback contract

imageUpload(files) receives a FileList or File array with the editor as this. Your callback handles failures and calls this.insertImage(url) for successful uploads. The editor does not consume a returned URL or catch custom callback rejections. Check this.node after awaiting work; register cancellation with this._onDispose() when needed. The working example is in demo.js.

Native forms and state

The original textarea submits the current HTML. Reset restores its initial value and clears undo history. Disabled fields follow native form rules; readonly content remains selectable and submitted.
